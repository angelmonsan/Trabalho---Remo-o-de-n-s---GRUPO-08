# Trabalho De Remoção de nós-GRUPO-08

Projeto desenvolvido em Java com o objetivo de demonstrar o funcionamento de uma Árvore Binária de Busca (BST) de forma simples, interativa e sem utilização de recursividade. O sistema permite inserir, remover, visualizar e limpar nós da árvore, além de mostrar o processo passo a passo no console para facilitar o entendimento.

---

# Funcionalidades

- Inserção de números;
- Remoção de nós;
- Exibição da árvore;
- Limpeza da árvore;
- Menu interativo;
- Explicação do processo no console;
- Testes para diferentes tipos de remoção.

---

# Tipos de Remoção Implementados

O sistema trata os principais casos de remoção em árvores binárias:

- Remoção de nó folha;
- Remoção de nó com apenas um filho;
- Remoção de nó com dois filhos;
- Remoção da raiz da árvore.

---

# Exibição da Árvore

A árvore mostra:

- valor do nó;
- tipo do nó (raiz, folha ou nó com filho);
- filhos esquerdo e direito;
- status do nó.
